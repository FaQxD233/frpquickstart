# FRP QuickStart 客户端安装指南

## 系统要求

- **操作系统**: Windows 10/11 (x64)
- **内存**: 最低 128MB
- **磁盘**: 50MB 可用空间
- **网络**: 能访问服务器的网络环境

## 一、下载客户端

### 从 GitHub Release 下载

访问 [Releases 页面](https://github.com/FaQxD233/frpquickstart/releases) 下载最新版本：

- **Windows x64**: `frpquick-client-win-x64.tar.gz`

解压到任意目录，例如：`C:\frpquickstart\`

## 二、获取服务器信息

在使用客户端前，需要从服务器管理员获取以下信息：

1. **服务器地址**: 例如 `54.178.226.167`
2. **API 密钥**: 从服务器配置文件获取
3. **TLS 模式**: 推荐 `acme`；如果服务器使用 `self-signed`，还需要 TLS 证书指纹

服务器管理员也可以直接发你一条 `frpquick://` 分享链接。分享链接已经包含服务器地址、控制端口、TLS 模式、API 密钥和自签证书指纹（如需要）。

### 如何获取服务器信息

如果你是服务器管理员，SSH 登录服务器后执行：

```bash
# 查看 API 密钥
cat ~/frpquickstart/server-config.json | grep ApiSecret

# 查看证书指纹
sudo journalctl -u frpquickstart | grep "TLS 证书指纹"
```

如果服务器使用 `acme` 模式，客户端不需要证书指纹，Windows 会按系统信任链验证 Let's Encrypt 证书。

## 三、使用方式

### 方式 1: 交互式配置（推荐新手）

双击 `frpquick-client.exe`，按提示输入。第一项可以填写服务器地址，也可以直接粘贴 `frpquick://` 分享链接：

```
1. 服务器地址或分享链接
2. 控制端口（默认 9080）
3. API 密钥
4. TLS 模式（none/self-signed/acme）
5. 证书指纹（仅 self-signed 模式）
6. 远程端口（公网端口）
7. 本地 IP（默认 127.0.0.1）
8. 本地端口
9. 协议（tcp/udp）
```

### 方式 2: 命令行参数（推荐高级用户）

在 PowerShell 或 CMD 中运行：

```cmd
frpquick-client.exe ^
  --server 54.178.226.167 ^
  --secret your-api-secret ^
  --tls acme ^
  --remote-port 25565 ^
  --local-port 25565 ^
  --protocol tcp
```

使用分享链接时，服务器/TLS/密钥配置会自动导入，只需要填写本地服务和公网端口：

```cmd
frpquick-client.exe ^
  --share "frpquick://54.178.226.167:9080/?tls=acme&secret=your-api-secret" ^
  --remote-port 25565 ^
  --local-port 25565 ^
  --protocol tcp
```

### 方式 3: 批处理文件（推荐日常使用）

创建 `start-tunnel.bat` 文件：

```batch
@echo off
frpquick-client.exe ^
  --server 54.178.226.167 ^
  --secret your-api-secret ^
  --tls acme ^
  --remote-port 25565 ^
  --local-port 25565 ^
  --protocol tcp
pause
```

双击运行即可启动隧道。

## 四、命令行参数说明

| 参数 | 说明 | 示例 | 必填 |
|------|------|------|------|
| `--share` | 服务端分享链接 | `frpquick://54.178.226.167:9080/?tls=acme&secret=...` | 否 |
| `--server` | 服务器地址 | `54.178.226.167` | 不使用 `--share` 时必填 |
| `--control-port` | 控制端口 | `9080` (默认) | 否 |
| `--secret` | API 密钥 | `7c9dc0006a4...` | 不使用 `--share` 时必填 |
| `--tls` | TLS 模式 | `none`/`self-signed`/`acme` | 否 |
| `--tls-fingerprint` | 证书指纹 | `4413D970...` | self-signed 时必填 |
| `--remote-port` | 公网端口 | `25565` | 是 |
| `--local-ip` | 本地 IP | `127.0.0.1` (默认) | 否 |
| `--local-port` | 本地端口 | `25565` | 是 |
| `--protocol` | 协议 | `tcp` (默认) / `udp` | 否 |

## 五、使用场景示例

### 场景 1: 内网穿透 Minecraft 服务器

```cmd
frpquick-client.exe ^
  --server your-server.com ^
  --secret your-api-secret ^
  --tls acme ^
  --remote-port 25565 ^
  --local-port 25565 ^
  --protocol tcp
```

玩家连接地址：`your-server.com:25565`

### 场景 2: 远程桌面穿透

```cmd
frpquick-client.exe ^
  --server your-server.com ^
  --secret your-api-secret ^
  --tls acme ^
  --remote-port 13389 ^
  --local-port 3389 ^
  --protocol tcp
```

远程桌面地址：`your-server.com:13389`

### 场景 3: Web 服务穿透

```cmd
frpquick-client.exe ^
  --server your-server.com ^
  --secret your-api-secret ^
  --tls acme ^
  --remote-port 18080 ^
  --local-port 80 ^
  --protocol tcp
```

访问地址：`http://your-server.com:18080`

### 场景 4: SSH 穿透

```cmd
frpquick-client.exe ^
  --server your-server.com ^
  --secret your-api-secret ^
  --tls acme ^
  --remote-port 12222 ^
  --local-port 22 ^
  --protocol tcp
```

SSH 连接：`ssh user@your-server.com -p 12222`

## 六、开机自启动（可选）

### 方法 1: 任务计划程序

1. 按 `Win + R`，输入 `taskschd.msc`
2. 创建基本任务
3. 触发器：计算机启动时
4. 操作：启动程序
5. 程序路径：`C:\frpquickstart\frpquick-client.exe`
6. 参数：填写命令行参数
7. 勾选"以最高权限运行"

### 方法 2: 启动文件夹

1. 按 `Win + R`，输入 `shell:startup`
2. 将 `start-tunnel.bat` 的快捷方式放入此文件夹
3. 重启电脑验证

### 方法 3: NSSM (推荐)

```cmd
# 下载 NSSM: https://nssm.cc/download
nssm install FrpQuickStart "C:\frpquickstart\frpquick-client.exe"
nssm set FrpQuickStart AppParameters "--server ... --secret ..."
nssm start FrpQuickStart
```

```cmd
# 测试端口连通性

Test-NetConnection -ComputerName your-server.com -Port 25565
```

## 八、常见问题

### 1. 无法连接服务器

**可能原因**：
- 服务器地址错误
- 服务器防火墙未开放端口
- API 密钥错误
- TLS 模式不匹配或证书验证失败

**排查步骤**：
```cmd
# 测试服务器控制端口（ACME 模式）
curl https://your-server.com:9080/health

# self-signed 模式检查 TLS 指纹是否正确
openssl s_client -connect your-server.com:9080 2>/dev/null | openssl x509 -noout -fingerprint -sha256
```

### 2. 端口被占用

客户端提示 "服务器端口 XXX 已被占用"：

**解决方案**：
- 选择其他未使用的远程端口
- 或联系服务器管理员释放端口

### 3. 本地服务无法访问

客户端连接成功，但公网无法访问本地服务：

**排查步骤**：
1. 确认本地服务已启动：`netstat -ano | findstr 25565`
2. 检查本地防火墙是否阻止
3. 确认 `--local-ip` 和 `--local-port` 配置正确

### 4. TLS 证书验证失败

提示 "无法通过 HTTPS 访问服务器健康检查"：

**解决方案**：
- `acme` 模式：确认服务器证书由 Let's Encrypt 签发，证书 SAN 包含服务器 IP 或域名
- `self-signed` 模式：检查证书指纹是否正确
- 确认服务器 TLS 模式与客户端配置一致
- 客户端不会在 HTTPS 失败后自动降级到 HTTP；需要修复 TLS 配置后重试

### 5. 连接频繁断开

**可能原因**：
- 网络不稳定
- 服务器负载过高
- 防火墙限制

**解决方案**：
- 检查网络连接
- 查看服务器日志：`sudo journalctl -u frpquickstart -f`
- 联系服务器管理员

## 九、高级配置

### 自定义 frpc 配置

客户端会自动生成 frpc 配置文件，位于 `runtime\frpc-{port}.toml`。

你可以手动编辑此文件添加高级配置（重启客户端后会被覆盖）：

```toml
serverAddr = "54.178.226.167"
serverPort = 7000
auth.method = "token"
auth.token = "xxx"

[[proxies]]
name = "custom-proxy"
type = "tcp"
localIP = "127.0.0.1"
localPort = 8080
remotePort = 18080
```

### 使用代理连接

如果需要通过代理连接服务器，设置环境变量：

```cmd
set HTTPS_PROXY=http://proxy.example.com:8080
frpquick-client.exe ...
```

## 十、性能优化

### 减少延迟

- 选择地理位置接近的服务器
- 使用有线网络代替 Wi-Fi
- 关闭不必要的后台程序

### 提高带宽

- 确认服务器带宽充足
- 检查本地上传速度
- 考虑升级服务器配置

## 十一、安全建议

1. **妥善保管 API 密钥**：不要在公开场合分享
2. **使用 TLS 加密**：生产环境必须启用 `self-signed` 或 `acme`
3. **定期更新**：及时升级到最新版本
4. **最小权限原则**：只开放必要的端口
5. **监控异常流量**：定期检查服务器日志

## 十二、卸载

1. 停止运行的客户端进程（Ctrl+C）
2. 删除程序文件夹：`C:\frpquickstart\`
3. 如果配置了开机自启，删除任务计划或启动项
