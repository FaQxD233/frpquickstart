# 客户端安装指南

客户端负责向服务端申请公网端口，生成 `frpc` 配置并启动内置 `frpc`。Windows 和 Linux 客户端都不需要单独安装 frp。

## 发布包

| 系统 | 文件 | 推荐用途 |
| --- | --- | --- |
| Windows x64 | `frpquick-client-win-x64.zip` | 普通桌面客户端 |
| Linux x64 | `frpquick-client-linux-x64.tar.gz` | Linux 主机、NAS、长期运行客户端 |

## Windows 客户端

下载 `frpquick-client-win-x64.zip`，解压到固定目录，例如：

```powershell
mkdir C:\frpquickstart\client
Expand-Archive .\frpquick-client-win-x64.zip -DestinationPath C:\frpquickstart\client -Force
cd C:\frpquickstart\client
```

使用分享链接启动：

```powershell
.\frpquick-client.exe `
  --share "frpquick://<服务器IP>:9080/?tls=acme&transport=tcp&secret=<API密钥>" `
  --remote-port 18080 `
  --local-ip 127.0.0.1 `
  --local-port 8080 `
  --protocol tcp
```

不传参数直接运行：

```powershell
.\frpquick-client.exe
```

程序会逐项询问服务端地址、端口、密钥和本地服务信息。第一项可以直接粘贴 `frpquick://` 分享链接。

## Linux 客户端一键安装

安装客户端并创建用户级 systemd 服务：

```bash
curl -fsSL https://github.com/FaQxD233/frpquickstart/releases/latest/download/install-client.sh \
  | bash -s -- \
      --share 'frpquick://<服务器IP>:9080/?tls=acme&transport=tcp&secret=<API密钥>' \
      --remote-port 18080 \
      --local-ip 127.0.0.1 \
      --local-port 8080 \
      --protocol tcp \
      --service
```

默认安装位置：

```text
~/.local/share/frpquickstart/client
```

默认命令链接：

```text
~/.local/bin/frpquick-client
```

查看用户服务：

```bash
systemctl --user status frpquick-client-18080 --no-pager
journalctl --user -u frpquick-client-18080 -f
```

只安装不创建服务：

```bash
curl -fsSL https://github.com/FaQxD233/frpquickstart/releases/latest/download/install-client.sh | bash
```

## Linux 客户端手动安装

```bash
wget https://github.com/FaQxD233/frpquickstart/releases/latest/download/frpquick-client-linux-x64.tar.gz
mkdir -p ~/frpquickstart-client
tar -xzf frpquick-client-linux-x64.tar.gz -C ~/frpquickstart-client
cd ~/frpquickstart-client
chmod +x frpquick-client
```

运行：

```bash
./frpquick-client \
  --share "frpquick://<服务器IP>:9080/?tls=acme&transport=tcp&secret=<API密钥>" \
  --remote-port 18080 \
  --local-ip 127.0.0.1 \
  --local-port 8080 \
  --protocol tcp
```

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| `--share` | 服务端分享链接，推荐使用 |
| `--server` | 服务端控制地址，不使用分享链接时填写 |
| `--control-port` | 控制端口，默认 `9080` |
| `--secret` | API 密钥，不使用分享链接时填写 |
| `--tls` | `acme`、`self-signed` 或 `none` |
| `--tls-fingerprint` | 自签证书 SHA256 指纹 |
| `--frp-transport` | frpc 连接 frps 的传输协议，通常由分享链接或服务端响应下发 |
| `--remote-port` | 服务端公网端口 |
| `--local-ip` | 本地服务监听 IP，默认 `127.0.0.1` |
| `--local-port` | 本地服务监听端口 |
| `--protocol` | `tcp` 或 `udp`，默认 `tcp` |
| `--frpc` | 自定义 frpc 路径，默认使用内置 frpc |

分享链接会覆盖服务端地址、控制端口、TLS 模式、frp 传输协议和 API 密钥。公网端口和本地服务端口仍由客户端填写。

注意：`--protocol` 表示业务隧道类型，只能是 `tcp` 或 `udp`。`--frp-transport` 表示客户端连接 frps 的底层传输方式，可用 `tcp`、`websocket`、`wss`、`kcp`、`quic`。正常使用时不需要手动填写，客户端会以服务端下发值为准。

## 示例

本地 Web 服务：

```powershell
.\frpquick-client.exe --share "<分享链接>" --remote-port 18080 --local-port 8080
```

Minecraft：

```powershell
.\frpquick-client.exe --share "<分享链接>" --remote-port 25565 --local-port 25565 --protocol tcp
```

远程桌面：

```powershell
.\frpquick-client.exe --share "<分享链接>" --remote-port 13389 --local-port 3389 --protocol tcp
```

UDP 服务：

```powershell
.\frpquick-client.exe --share "<分享链接>" --remote-port 19000 --local-port 19000 --protocol udp
```

## TLS 说明

`acme` 模式下，客户端按系统信任链验证 Let's Encrypt 证书，不需要证书指纹。

`self-signed` 模式下，客户端必须配置服务端打印的证书指纹：

```powershell
.\frpquick-client.exe `
  --server <服务器IP> `
  --tls self-signed `
  --tls-fingerprint <SHA256指纹> `
  --secret <API密钥> `
  --remote-port 18080 `
  --local-port 8080
```

客户端发现 TLS 配置不匹配时会直接退出，不会自动降级到明文 HTTP。

## 排障

端口被占用：

- 登录 Web 管理界面清理离线记录。
- 确认云安全组和系统防火墙已放行业务端口。
- 确认本地服务确实监听了 `--local-ip` 和 `--local-port`。

查看 Linux 客户端服务日志：

```bash
journalctl --user -u frpquick-client-18080 -n 120 --no-pager
```

Windows 客户端启动后不要关闭窗口。窗口关闭后，隧道也会停止。
