# Web 管理界面使用指南

## 简介

FRP QuickStart 内置 Web 管理界面，无需安装额外组件，直接通过浏览器访问即可查看和管理隧道。

## 访问地址

```
https://your-server-ip:9080/admin
```

例如：`https://54.178.226.167:9080/admin`

首次访问会要求输入 API 密钥。该密钥就是服务端 `server-config.json` 中的 `ApiSecret`，也和 Windows 客户端连接时使用的 `--secret` 一致。

## 功能特性

### 📊 实时统计

管理界面顶部显示三个关键指标：

- **历史隧道总数**: 所有创建过的隧道数量
- **独立客户端数**: 不同客户端的数量
- **已占用端口数**: 当前正在使用的公网端口数量

### 📋 隧道列表

表格形式展示所有隧道记录，包含以下信息：

| 列 | 说明 |
|----|------|
| 状态 | 当前端口是否仍被占用，在线表示隧道仍在运行 |
| 客户端名称 | Windows 客户端的计算机名 |
| 协议 | TCP 或 UDP |
| 本地地址 | 本地 IP:端口 |
| 公网端口 | 服务器分配的公网端口 |
| 代理名称 | FRP 内部代理标识 |
| 创建时间 | 隧道创建的时间戳 |
| 操作 | 释放离线端口，或强制关闭在线隧道 |

### 释放端口和清理旧记录

客户端异常退出后，frps 通常会释放公网端口，但控制面历史记录可能仍然存在。新版服务端在客户端再次申请指定端口时会实时检查端口是否已经可用，并自动移除内存中的旧占用，避免离线老隧道导致 409 冲突。

管理界面也提供手动处理入口：

- **释放端口**：用于离线隧道，删除该隧道记录并释放服务端内存端口占用。
- **清理离线记录**：批量删除所有已经不再占用公网端口的历史记录。
- **强制关闭**：用于在线隧道。由于当前 frps dashboard API 没有可靠的单隧道删除接口，该操作会重启由 `frpquick-server` 托管的 `frps`，所有在线隧道都会断开。客户端进程保持运行时会自动重连。

### 🔄 自动刷新

- 页面每 30 秒自动刷新数据
- 点击右上角 "🔄 刷新" 按钮可手动刷新

## 使用场景

### 1. 查看当前活跃隧道

通过"已占用端口数"和隧道列表，可以快速了解哪些端口正在使用。

### 2. 排查端口冲突

如果客户端提示"端口已被占用"，可以在管理界面查看该端口是否真的在线。离线记录可直接释放；如果端口已不再被系统占用，也可以点击"清理离线记录"批量清掉。

### 3. 审计隧道历史

隧道列表显示所有历史记录，方便审计和追踪。

### 4. 监控客户端连接

通过"独立客户端数"可以了解有多少台设备连接到服务器。

## API 接口

管理界面基于以下 API 构建，你也可以直接调用：

### GET /api/stats

获取统计信息

请求需要认证：

```bash
curl -H "X-Api-Secret: <API密钥>" https://your-server-ip:9080/api/stats
```

**响应示例**：
```json
{
  "Success": true,
  "TotalTunnels": 15,
  "UniqueClients": 3,
  "OccupiedPorts": [18080, 28080, 38080]
}
```

### GET /api/tunnels/list

获取隧道列表

请求需要认证：

```bash
curl -H "X-Api-Secret: <API密钥>" https://your-server-ip:9080/api/tunnels/list
```

**响应示例**：
```json
{
  "Success": true,
  "Tunnels": [
    {
      "Time": "2026-06-17T17:00:25.9415757+00:00",
      "Protocol": "tcp",
      "RemotePort": 38080,
      "LocalIp": "127.0.0.1",
      "LocalPort": 8080,
      "ClientName": "DESKTOP-XXX",
      "ProxyName": "DESKTOP-XXX-tcp-38080"
    }
  ]
}
```

### POST /api/tunnels/release

释放单个隧道记录对应的端口。离线隧道可直接释放；在线隧道需要传 `Force: true`，并且只有 frps 是由 `frpquick-server` 托管启动时才能执行。

```bash
curl -X POST \
  -H "X-Api-Secret: <API密钥>" \
  -H "Content-Type: application/json" \
  -d '{"RemotePort":38080,"Protocol":"tcp","ProxyName":"","Force":false}' \
  https://your-server-ip:9080/api/tunnels/release
```

在线隧道强制关闭示例：

```bash
curl -X POST \
  -H "X-Api-Secret: <API密钥>" \
  -H "Content-Type: application/json" \
  -d '{"RemotePort":38080,"Protocol":"tcp","Force":true}' \
  https://your-server-ip:9080/api/tunnels/release
```

注意：`Force: true` 会重启 `frps`，所有在线隧道都会断开。

### POST /api/tunnels/prune-offline

批量清理所有离线隧道记录，并释放服务端内存中的旧端口占用。

```bash
curl -X POST \
  -H "X-Api-Secret: <API密钥>" \
  https://your-server-ip:9080/api/tunnels/prune-offline
```

## 安全建议

### 当前安全措施

- ✅ 使用 HTTPS (TLS 加密)
- ✅ 内置 API 密钥认证
- ✅ 与控制端口共享 (9080)
- ✅ 管理操作只允许通过 API 密钥认证后执行

### 额外加固（可选）

如果需要更高的安全性，可以考虑：

1. **反向代理二次认证**
   ```nginx
   # 使用 Nginx 反向代理添加认证
   location /admin {
       auth_basic "FRP QuickStart";
       auth_basic_user_file /etc/nginx/.htpasswd;
       proxy_pass https://localhost:9080;
   }
   ```

2. **IP 白名单**
   ```nginx
   # 只允许特定 IP 访问管理界面
   location /admin {
       allow 1.2.3.4;
       deny all;
       proxy_pass https://localhost:9080;
   }
   ```

3. **VPN 访问**
   - 通过 VPN 连接到服务器后再访问管理界面

## 故障排查

### 无法访问管理界面

1. **检查服务是否运行**
   ```bash
   sudo systemctl status frpquickstart
   ```

2. **检查端口监听**
   ```bash
   ss -tlnp | grep 9080
   ```

3. **检查防火墙**
   ```bash
   sudo ufw status | grep 9080
   ```

4. **测试 API**
   ```bash
   curl -k -H "X-Api-Secret: <API密钥>" https://localhost:9080/api/stats
   ```

### 数据不显示

1. **检查隧道记录文件**
   ```bash
   cat ~/frpquickstart/runtime/tunnels.jsonl
   ```

2. **浏览器控制台**
   - 按 F12 打开开发者工具
   - 查看 Console 和 Network 标签页

### 自签名证书警告

浏览器会提示"您的连接不是私密连接"，这是正常的：

1. 点击 "高级" 或 "Advanced"
2. 点击 "继续访问" 或 "Proceed to ..."
3. 或者在浏览器中添加证书例外

## 集成到现有工具

### 使用 curl

```bash
# 获取统计信息
curl -H "X-Api-Secret: <API密钥>" https://your-server:9080/api/stats | jq

# 获取隧道列表
curl -H "X-Api-Secret: <API密钥>" https://your-server:9080/api/tunnels/list | jq '.Tunnels'
```

### 使用 Python

```python
import requests

# 获取统计
headers = {'X-Api-Secret': '<API密钥>'}
response = requests.get('https://your-server:9080/api/stats', headers=headers)
stats = response.json()
print(f"总隧道数: {stats['TotalTunnels']}")

# 获取隧道列表
response = requests.get('https://your-server:9080/api/tunnels/list', headers=headers)
tunnels = response.json()['Tunnels']
for tunnel in tunnels:
    print(f"{tunnel['ClientName']} - {tunnel['RemotePort']}")
```
