# Web 管理界面使用指南

服务端内置 Web 管理界面，用于查看隧道、清理离线记录和释放端口。

## 访问地址

```text
https://<服务器IP>:9080/admin
```

如果服务端使用 `self-signed` TLS，浏览器会提示证书不受信任。确认地址无误后继续访问即可。`acme` 模式下浏览器应正常信任证书。

## 登录

登录密钥是 `server-config.json` 中的 `ApiSecret`。它也是客户端连接时使用的 API 密钥。

查看密钥：

```bash
sudo cat /opt/frpquickstart/server/server-config.json | grep ApiSecret
```

如果使用手动安装路径，请按实际目录查看 `server-config.json`。

## 页面内容

统计区显示：

| 项 | 说明 |
| --- | --- |
| 历史隧道总数 | 记录文件中的隧道条数 |
| 独立客户端数 | 按客户端名称去重后的数量 |
| 已占用端口数 | 当前仍被系统占用的公网端口数量 |

隧道列表显示：

| 列 | 说明 |
| --- | --- |
| 状态 | 在线或离线 |
| 客户端名称 | 客户端机器名 |
| 协议 | TCP 或 UDP |
| 本地地址 | 客户端本地服务地址 |
| 公网端口 | 服务端对外端口 |
| 代理名称 | frp proxy 名称 |
| 创建时间 | 隧道申请时间 |
| 操作 | 释放端口或强制关闭 |

页面每 30 秒自动刷新，也可以手动点击“刷新”。

## 清理离线记录

客户端异常退出后，frps 通常会释放公网端口，但历史记录仍会留在 `runtime/tunnels.jsonl`。点击“清理离线记录”会删除已经不再占用端口的记录，并释放服务端内存中的旧端口占用。

新版服务端在处理新的指定端口申请时，也会先检查端口是否已经实际空闲。如果端口空闲，会自动移除旧的内存占用，避免离线老记录造成 409 冲突。

## 释放端口

离线隧道行显示“释放端口”。点击后会删除该隧道记录，并释放对应公网端口的控制面占用。

## 强制关闭在线隧道

在线隧道行显示“强制关闭”。该操作会重启由 FRP QuickStart 托管的 `frps`。

影响：

- 所有在线隧道都会断开。
- 正在运行的客户端会自动重新连接。
- 如果 `frps` 不是由 `frpquick-server` 启动，强制关闭会被拒绝。

当前 frps dashboard API 没有可靠的单隧道删除接口，所以这里采用重启托管 `frps` 的方式释放在线端口。

## 管理 API

所有管理 API 都需要请求头：

```text
X-Api-Secret: <API密钥>
```

### GET /api/stats

获取统计信息：

```bash
curl -H "X-Api-Secret: <API密钥>" https://<服务器IP>:9080/api/stats
```

响应示例：

```json
{
  "Success": true,
  "TotalTunnels": 2,
  "UniqueClients": 1,
  "OccupiedPorts": [18080]
}
```

### GET /api/tunnels/list

获取隧道列表：

```bash
curl -H "X-Api-Secret: <API密钥>" https://<服务器IP>:9080/api/tunnels/list
```

### POST /api/tunnels/prune-offline

批量清理离线记录：

```bash
curl -X POST \
  -H "X-Api-Secret: <API密钥>" \
  https://<服务器IP>:9080/api/tunnels/prune-offline
```

### POST /api/tunnels/release

释放单个离线端口：

```bash
curl -X POST \
  -H "X-Api-Secret: <API密钥>" \
  -H "Content-Type: application/json" \
  -d '{"RemotePort":18080,"Protocol":"tcp","Force":false}' \
  https://<服务器IP>:9080/api/tunnels/release
```

强制关闭在线隧道：

```bash
curl -X POST \
  -H "X-Api-Secret: <API密钥>" \
  -H "Content-Type: application/json" \
  -d '{"RemotePort":18080,"Protocol":"tcp","Force":true}' \
  https://<服务器IP>:9080/api/tunnels/release
```

`Force: true` 会重启托管的 `frps`，所有在线隧道都会断开。

## 排障

无法打开管理界面：

```bash
sudo systemctl status frpquickstart --no-pager
sudo ss -tlnp | grep 9080
```

API 返回 401：

- 确认 `X-Api-Secret` 使用的是服务端 `ApiSecret`。
- 浏览器登录失败时清空本地存储后重新访问 `/admin`。

统计不准确：

- 点击“刷新”。
- 点击“清理离线记录”。
- 确认对应公网端口是否被其他进程占用。
