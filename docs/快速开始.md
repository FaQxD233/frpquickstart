# 快速开始

本文按最常见的部署方式说明：Linux VPS 运行服务端，Windows 电脑运行客户端。其他组合见服务端和客户端安装指南。

## 1. 安装 Linux 服务端

在 VPS 上执行：

```bash
PUBLIC_IP="$(curl -4fsSL https://ip.sb)"

curl -fsSL https://github.com/FaQxD233/frpquickstart/releases/latest/download/install-server.sh \
  | sudo bash -s -- \
      --tls acme \
      --acme-id "$PUBLIC_IP" \
      --acme-email admin@example.com
```

脚本会完成以下操作：

- 下载 `frpquick-server-linux-x64.tar.gz`
- 安装到 `/opt/frpquickstart/server`
- 创建并启动 `frpquickstart.service`
- 在 `--tls acme` 模式下安装或复用 `acme.sh`

查看日志：

```bash
sudo journalctl -u frpquickstart -n 80 --no-pager
```

记录日志中的 `frpquick://...` 分享链接。它包含服务端地址、控制端口、TLS 模式和 API 密钥。

## 2. 放行端口

在云安全组和系统防火墙中放行：

```bash
sudo ufw allow 80/tcp
sudo ufw allow 9080/tcp
sudo ufw allow 7000/tcp
sudo ufw allow 18080/tcp
sudo ufw reload
```

端口说明：

- `80/tcp`: ACME 校验
- `9080/tcp`: 控制接口和 Web 管理界面
- `7000/tcp`: frpc 连接 frps
- `18080/tcp`: 示例业务端口，可换成自己的公网端口

## 3. 运行 Windows 客户端

下载 `frpquick-client-win-x64.zip`，解压后进入目录：

```powershell
.\frpquick-client.exe `
  --share "frpquick://<服务器IP>:9080/?tls=acme&secret=<API密钥>" `
  --remote-port 18080 `
  --local-ip 127.0.0.1 `
  --local-port 8080 `
  --protocol tcp
```

本机如果有 HTTP 服务监听 `127.0.0.1:8080`，外部访问地址就是：

```text
http://<服务器IP>:18080/
```

## 4. 管理隧道

访问：

```text
https://<服务器IP>:9080/admin
```

使用 `ApiSecret` 登录。`ApiSecret` 在服务端的 `server-config.json` 中，也会出现在服务端首次启动日志和分享链接里。

客户端异常退出后，如果再次申请同一个公网端口提示占用，可以在管理界面点击“清理离线记录”或在对应隧道行点击“释放端口”。

## 5. 常用示例

Minecraft：

```powershell
.\frpquick-client.exe --share "<分享链接>" --remote-port 25565 --local-port 25565 --protocol tcp
```

Web 服务：

```powershell
.\frpquick-client.exe --share "<分享链接>" --remote-port 18080 --local-port 8080 --protocol tcp
```

远程桌面：

```powershell
.\frpquick-client.exe --share "<分享链接>" --remote-port 13389 --local-port 3389 --protocol tcp
```
