# 快速开始

5 分钟内完成内网穿透配置！

## 服务端快速部署（Linux）

```bash
# 1. 下载并解压
wget https://github.com/FaQxD233/frpquickstart/releases/download/v1.0/frpquick-server-linux-x64.tar.gz
mkdir frpquickstart && tar -xzf frpquick-server-linux-x64.tar.gz -C frpquickstart
cd frpquickstart

# 2. 启动服务（选择 self-signed 模式）
./frpquick-server
# 按提示选择 TLS 模式: self-signed
# 记录屏幕上显示的 API 密钥和证书指纹

# 3. 配置防火墙
sudo ufw allow 9080/tcp
sudo ufw allow 7000/tcp
sudo ufw allow 10000:60000/tcp
```

**记录以下信息**：
- ✅ API 密钥
- ✅ TLS 证书指纹
- ✅ 服务器公网 IP

## 客户端快速使用（Windows）

```cmd
# 1. 下载并解压 frpquick-client-win-x64.zip

# 2. 创建 start.bat 文件
frpquick-client.exe ^
  --server <你的服务器IP> ^
  --secret <API密钥> ^
  --tls self-signed ^
  --tls-fingerprint <证书指纹> ^
  --remote-port 25565 ^
  --local-port 25565

# 3. 运行 start.bat
```

## 验证连接

```cmd
# 测试公网访问
telnet <服务器IP> 25565
```

成功！你的本地服务现在可以从公网访问了。

## 使用场景

### Minecraft 服务器
```cmd
--remote-port 25565 --local-port 25565 --protocol tcp
```

### 远程桌面
```cmd
--remote-port 13389 --local-port 3389 --protocol tcp
```

### Web 服务
```cmd
--remote-port 18080 --local-port 80 --protocol tcp
```

### SSH
```cmd
--remote-port 12222 --local-port 22 --protocol tcp
```
