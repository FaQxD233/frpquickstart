# 快速开始

5 分钟内完成内网穿透配置！

## 服务端快速部署（Linux）

先在 Windows 本机生成发布包并上传到 VPS：

```powershell
# 1. 在项目根目录生成 Linux 服务端发布包
powershell -ExecutionPolicy Bypass -File .\release\publish-linux-x64.ps1
Copy-Item -Force .\artifacts\linux-x64-self-contained\server\frpquick-server .\release\server-linux-x64\frpquick-server
tar -czf .\release\frpquick-server-linux-x64.tar.gz -C .\release\server-linux-x64 frpquick-server

# 2. 上传到 VPS
scp -i "C:\path\to\key.pem" .\release\frpquick-server-linux-x64.tar.gz ubuntu@<你的公网IP>:/home/ubuntu/
```

然后 SSH 登录 VPS 解压并启动：

```bash
# 1. 解压
mkdir frpquickstart && tar -xzf frpquick-server-linux-x64.tar.gz -C frpquickstart
cd frpquickstart
chmod +x frpquick-server

# 2. 安装 acme.sh（ACME 模式需要）
curl https://get.acme.sh | sh -s email=admin@example.com

# 3. 启动服务（推荐 ACME shortlived IP 证书）
./frpquick-server --tls acme --acme-id <你的公网IP> --acme-email admin@example.com
# 记录首次显示的 API 密钥，或直接复制服务端打印的 frpquick:// 分享链接

# 4. 配置防火墙/云安全组
sudo ufw allow 80/tcp
sudo ufw allow 9080/tcp
sudo ufw allow 7000/tcp
sudo ufw allow 10000:60000/tcp
```

**记录以下信息**：
- ✅ API 密钥
- ✅ 服务器公网 IP
- ✅ TLS 模式：`acme`
- ✅ 客户端分享链接：`frpquick://...`

如果不能使用 ACME，也可以用 `./frpquick-server --tls self-signed`，此时需要额外记录服务端打印的 TLS 证书指纹。

## 客户端快速使用（Windows）

先在 Windows 本机生成并解压客户端包：

```powershell
powershell -ExecutionPolicy Bypass -File .\release\publish-win-x64.ps1
Copy-Item -Force .\artifacts\win-x64-self-contained\client\frpquick-client.exe .\release\client-win-x64\frpquick-client.exe
tar -czf .\release\frpquick-client-win-x64.tar.gz -C .\release\client-win-x64 frpquick-client.exe

mkdir C:\frpquickstart
tar -xzf .\release\frpquick-client-win-x64.tar.gz -C C:\frpquickstart
cd C:\frpquickstart
```

创建 `start.bat`：

```cmd
frpquick-client.exe ^
  --server <你的服务器IP> ^
  --secret <API密钥> ^
  --tls acme ^
  --remote-port 25565 ^
  --local-port 25565

# 或直接使用分享链接导入服务器/TLS/密钥配置
frpquick-client.exe ^
  --share "frpquick://<你的服务器IP>:9080/?tls=acme&secret=<API密钥>" ^
  --remote-port 25565 ^
  --local-port 25565

# 保存后双击运行 start.bat
```

## 验证连接

```cmd
# 测试公网访问
telnet <服务器IP> 25565
```

成功！你的本地服务现在可以从公网访问了。

如果客户端异常退出后再次指定同一个公网端口时报"端口已被占用"，访问 `https://<服务器IP>:9080/admin`，用 API 密钥登录后点击"清理离线记录"或在对应隧道行点击"释放端口"。

## 使用场景

### Minecraft 服务器
```cmd
--remote-port 25565 --local-port 25565 --protocol tcp
```

### 远程桌面
```cmd
--remote-port 13389 --local-port 3389 --protocol tcp
```

### Web 服务
```cmd
--remote-port 18080 --local-port 80 --protocol tcp
```

### SSH
```cmd
--remote-port 12222 --local-port 22 --protocol tcp
```
