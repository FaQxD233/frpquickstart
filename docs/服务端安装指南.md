# 服务端安装指南

服务端负责控制接口、Web 管理界面和 `frps` 进程。生产环境推荐 Linux VPS；Windows 服务端适合测试或临时内网环境。

## 发布包

| 系统 | 文件 | 推荐用途 |
| --- | --- | --- |
| Linux x64 | `frpquick-server-linux-x64.tar.gz` | VPS 长期运行 |
| Windows x64 | `frpquick-server-win-x64.zip` | 本机测试、临时服务端 |

服务端包已经内置对应平台的 `frps`。首次运行时会释放到 `runtime/frp/`。

## Linux 一键安装

在 VPS 上执行：

```bash
PUBLIC_IP="$(curl -4fsSL https://ip.sb)"

curl -fsSL https://github.com/FaQxD233/frpquickstart/releases/latest/download/install-server.sh \
  | sudo bash -s -- \
      --tls acme \
      --acme-id "$PUBLIC_IP" \
      --acme-email admin@example.com
```

默认安装位置：

```text
/opt/frpquickstart/server
```

默认 systemd 服务：

```text
frpquickstart.service
```

查看状态和日志：

```bash
sudo systemctl status frpquickstart --no-pager
sudo journalctl -u frpquickstart -f
```

常用安装参数：

```bash
--version v1.2
--install-dir /opt/frpquickstart/server
--service-name frpquickstart
--tls acme
--acme-id 1.2.3.4
--acme-email admin@example.com
--no-service
```

## Linux 手动安装

```bash
wget https://github.com/FaQxD233/frpquickstart/releases/latest/download/frpquick-server-linux-x64.tar.gz
mkdir -p ~/frpquickstart
tar -xzf frpquick-server-linux-x64.tar.gz -C ~/frpquickstart
cd ~/frpquickstart
chmod +x frpquick-server
```

启动：

```bash
PUBLIC_IP="$(curl -4fsSL https://ip.sb)"
./frpquick-server --tls acme --acme-id "$PUBLIC_IP" --acme-email admin@example.com
```

## Windows 服务端

下载 `frpquick-server-win-x64.zip`，解压后运行：

```powershell
.\frpquick-server.exe --tls self-signed
```

Windows 下不推荐使用 `--tls acme`，因为本项目的 ACME 模式依赖 `acme.sh` 和 standalone HTTP-01 校验。Windows 服务端建议使用 `self-signed`，客户端需要配置服务端日志中打印的证书指纹。

## 防火墙

Linux VPS 至少放行：

```bash
sudo ufw allow 80/tcp
sudo ufw allow 9080/tcp
sudo ufw allow 7000/tcp
sudo ufw allow 10000:60000/tcp
sudo ufw reload
```

端口说明：

- `80/tcp`: ACME HTTP-01 校验
- `9080/tcp`: 控制接口和 Web 管理界面
- `7000/tcp`: frpc 连接 frps
- `10000:60000/tcp`: 默认允许的公网业务端口范围

云服务器还需要在安全组中放行同样的端口。

## TLS 模式

### acme

推荐用于生产环境：

```bash
./frpquick-server --tls acme --acme-id 1.2.3.4 --acme-email admin@example.com
```

服务端会调用 `acme.sh` 申请 Let's Encrypt short-lived IP 证书，并安装到：

```text
runtime/acme/fullchain.pem
runtime/acme/key.pem
```

`acme.sh` 的定时任务只在续签时短暂监听 `80/tcp`。证书文件更新后，服务端会在新连接握手前自动重新加载。

如果 `80/tcp` 长期被其他服务占用，ACME standalone 校验会失败。已有证书仍可继续使用到过期；到期前需要释放 80 端口或改用其他 ACME 校验方式。

### self-signed

```bash
./frpquick-server --tls self-signed
```

服务端会生成自签证书并打印 SHA256 指纹。客户端必须配置这个指纹。

### none

```bash
./frpquick-server --tls none
```

只适合本机测试或受信网络。该模式会明文传输 API 密钥。

## 配置文件

首次运行会生成 `server-config.json`。常用字段：

| 字段 | 说明 |
| --- | --- |
| `PublicAddress` | 服务端公网 IP 或域名 |
| `ControlPort` | 控制端口，默认 `9080` |
| `FrpsBindPort` | frps 端口，默认 `7000` |
| `ApiSecret` | 控制接口和客户端认证密钥 |
| `FrpAuthToken` | frpc/frps 认证 token |
| `AllowedRemotePortStart` | 允许申请的最小公网端口 |
| `AllowedRemotePortEnd` | 允许申请的最大公网端口 |
| `TlsMode` | `acme`、`self-signed` 或 `none` |

修改配置后重启服务：

```bash
sudo systemctl restart frpquickstart
```

## 分享链接

服务端启动后会打印：

```text
frpquick://<服务器IP>:9080/?tls=acme&secret=<API密钥>
```

客户端粘贴后会自动导入服务端地址、控制端口、TLS 模式和 API 密钥。链接包含密钥，只发给可信用户。

## 升级

一键安装方式升级：

```bash
PUBLIC_IP="$(curl -4fsSL https://ip.sb)"

curl -fsSL https://github.com/FaQxD233/frpquickstart/releases/latest/download/install-server.sh \
  | sudo bash -s -- \
      --tls acme \
      --acme-id "$PUBLIC_IP" \
      --acme-email admin@example.com
```

手动升级：

```bash
sudo systemctl stop frpquickstart
cp -r /opt/frpquickstart/server/runtime /opt/frpquickstart/runtime.bak
cp /opt/frpquickstart/server/server-config.json /opt/frpquickstart/server-config.json.bak

wget https://github.com/FaQxD233/frpquickstart/releases/latest/download/frpquick-server-linux-x64.tar.gz
tar -xzf frpquick-server-linux-x64.tar.gz -C /opt/frpquickstart/server
chmod +x /opt/frpquickstart/server/frpquick-server

cp /opt/frpquickstart/server-config.json.bak /opt/frpquickstart/server/server-config.json
cp -r /opt/frpquickstart/runtime.bak/* /opt/frpquickstart/server/runtime/
sudo systemctl start frpquickstart
```

## 卸载

```bash
sudo systemctl stop frpquickstart
sudo systemctl disable frpquickstart
sudo rm -f /etc/systemd/system/frpquickstart.service
sudo systemctl daemon-reload
sudo rm -rf /opt/frpquickstart/server
```

## 排障

端口占用：

```bash
sudo ss -tlnp | grep -E ':(80|9080|7000)'
```

服务日志：

```bash
sudo journalctl -u frpquickstart -n 120 --no-pager
```

健康检查：

```bash
curl https://<服务器IP>:9080/health
```

如果客户端指定端口时提示占用，先进入 Web 管理界面清理离线记录：

```text
https://<服务器IP>:9080/admin
```
